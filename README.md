PennylessTrack es una aplicación orientada al seguimiento, control y gestión de finanzas y gastos personales de forma sencilla, intuitiva y segura.

---

## 📖 Descripción del proyecto
PennylessTrack proporciona a los usuarios una herramienta centralizada para monitorear presupuestos, registrar transacciones cotidianas, clasificar gastos e ingresos por categorías y visualizar el balance financiero mensual en tiempo real.

### Características principales
- Registro ágil y categorización de movimientos monetarios.
- Resúmenes y métricas de balance mensual.
- Enfoque riguroso en privacidad y seguridad de datos.

---

## 🛠️ Tecnologías utilizadas
- **Lenguajes:** JavaScript / TypeScript / Python
- **Entorno / Frameworks:** Node.js / React
- **Control de versiones:** Git y GitHub
- **Seguridad:** Gitleaks (escaneo preventivo de secretos y credenciales)
